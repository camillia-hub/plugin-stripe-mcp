# Stripe MCP

The official Stripe MCP server. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/@stripe/mcp

Installs from the Camillia hub as `stripe-mcp-05a308`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
